## HE BUGS - App android para aprimorar experiencia e personalizar o jogo Heroes Evolved (Permitido pela NetDragon Websoft)

Aplicativo bem complexo construido no DroidScript usando JS e funções próprias que permitia aos usuarios, modificar o jogo de várias formas, deixando o jogo bem mais personalizavel, foi um projeto MUITO popular,
descontinuado por falta de tempo na epoca :(

parte das funções desse app foi integrada ao proprio jogo pela NetDragon anos depois.

o app contava com funções para Melhorar o FPS, ver Ping do Jogo, mudar telas de carregamento, splash arts, skins, salvar imagens e videos do jogo para ser usados por criadores de conteúdo, e muito mais.
